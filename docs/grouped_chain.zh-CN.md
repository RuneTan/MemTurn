# 分组探索任务流

[English](grouped_chain.md) | [简体中文](grouped_chain.zh-CN.md)

这是定性的开发检查，不是正式持续学习结果。

当前运行器同时冻结协议版本和配置。2026-10-23 的原任务流使用旧提示和训练协议，不能在修复后的代码上直接续跑并声称方法未变。原运行应保留，修复版使用新输出目录；复现旧版续跑需使用当时的代码版本。

计划共 500 个任务，每组 20 个，条件循环为 `vault:v1`、`api:v1`、`vault:v2`、`api:v2`。这是两个合成任务族中的四条已知规则，不是 500 种技能或标准任务。

本地任务模型为 Qwen3-1.7B，Writer 为 Groq GPT-OSS 120B，巩固使用确定性开发组件。固定秩 LoRA 从已发布版本延续。当前配置在合格的四任务批次后，将选中条目的样本打乱并完整训练一遍，每样本更新一次。原试跑使用两次更新的工程设置，这不是架构要求。任务和记忆预算沿用本地配置。

## 额度规则

此前试跑每任务约使用 1200 个 Writer tokens。若每日额度为 200k，忽略此前账户用量及波动，大约支持 160 个类似任务。实际探索运行将提供商报告的非缓存 Writer tokens 限制为 180k，在下一请求前预留余量，并遵守实际额度错误。只有提供商明确报告缓存 tokens 时才扣除该部分，账户实际计费以提供商为准。

达到配置预算或服务额度后，运行保存任务完成数和延后的 Writer 来源并停止，不升级付费，也不用伪造经验替代。分钟限流只进行有限重试。报告分别列出完整计划和实际执行任务数。

本开发入口的额度按显式启动计算。额度恢复后再执行 `--resume`，会获得新的本地额度，同时保留累计用量、任务数、LoRA 和记忆；这不会重置提供商额度。

## 记录什么

- 每个任务：收益、是否完成、首动作、步数、记忆占用、来源存储、adapter 数量、CUDA 分配量和采样进程内存。
- 每次 Writer 调用：最终原始回复和返回的用量，写入审计。
- 每个已解析候选：校验前的完整记忆记录，包括被拒候选；完整来源轨迹也留在审计中。
- 启动时和每个组边界：在固定留出对象上，组合基础／当前 adapter 与无／有记忆做配对首动作探针。探针不提供反馈、不写经验，也不刷新记忆访问时间。

同一记忆库上的配对探针是诊断，不是四套独立学习基线。直接首动作指标把搜索请求计为“尚未执行正确环境动作”。训练观察可能包含明确纠错反馈，因此另报告无反馈探针。

## 运行与续跑

在启动进程配置好 `MEMTURN_WRITER_API_KEY` 后运行：

```text
.venv-local/Scripts/python.exe run_memturn.py long-chain --output runs/your_chain --tasks 500 --group-size 20 --writer-token-budget 180000
```

正常暂停后，用同一命令加 `--resume` 继续，配置指纹须一致。延后的 Writer 来源重试不会新增或重做任务。这只实现完整暂停边界的恢复，不是任意崩溃位置都能保证任务恰好执行一次；数据库与检查点不一致时拒绝恢复。

维护后原子替换 `checkpoint.json` 和 `report.json`。`metrics.jsonl` 记录每任务指标，`probes.jsonl` 记录探针。`bank_*.json` 和审计属于观察资料，不向 Agent 开放；它们计入实验输出存储，不暗中充当额外记忆。

在选定分析环境中安装 Matplotlib 后，可离线运行：

```text
python scripts/summarize_chain.py runs/your_chain
```

输出包括 `analysis/summary.json`、中文分组报告、带证据的 Writer 示例及 PNG／SVG 图。运行尚未结束时也可查看进度，分析不调用模型。

任务链暂停后，还可运行独立的本地完整任务诊断：

```text
.venv-local/Scripts/python.exe scripts/evaluate_chain.py runs/your_chain
python scripts/summarize_chain.py runs/your_chain
```

该诊断在相同四种模型／记忆组合下执行 32 个留出回合，检查学习状态不变，记录完整动作轨迹，不调用 Writer、不训练。组末外部库可能因内化而为空，此时有／无记忆结果重合不能识别记忆作用。

额外选项 `--show-tool-state` 向任务模型提供剩余搜索数、上一次查询及返回引用，不提供正确动作。它生成独立结果，在相同末态任务上比较可见性干预，不改变原主任务流，也不能据此认定正式工具历史功能已经实现。
