# 开发说明

[English](development.md) | [简体中文](development.zh-CN.md)

核心只需要 Python 3.10+ 和标准库。在自己的仓库副本和 Python 环境中运行：

```text
python -m pip install -e .
python -X utf8 -m unittest discover -s tests -t . -v
```

测试使用临时数据库、确定性替身和假学习器，检查来源、有界状态、事务回滚、版本退出、快照隔离与恢复。测试替身位于 `tests/fixtures`，不随库安装，不属于实验数据或标准任务结果。不需要下载模型、配置 API 密钥或连接外部服务。

可选 `runtime` 依赖提供资源监测所需的 psutil；原生环境包装需要另行管理依赖和资产。仓库没有实验命令行入口，也没有选定模型后端。

增加应用后端时，先检查证据准入、训练材料屏蔽、token 计费、取消操作和候选加载，再允许发布版本。尤其需要确认训练失败保留目标记忆、旧任务继续使用固定版本。实际硬件限制与科学评估需另行验收。

安装和测试只能验证工程约定，不能证明模型质量、训练效果或标准任务表现。

`tests/test_material_recovery.py` 覆盖文字重合、逐样本保留、重复引用与样本、数量限制及发布。文字重合只记录提示，伪造动作和越界引用仍被拒绝；原生历史保留，历史检索消息不带入学生输入。

`tests/test_training_and_cold_selection.py` 检查完整训练输入送达、冷区不受原有条数截断、实际输入半预算保留，以及失败时保留原状态。旧学习器须更新为完整接口，旧配置须移除 `cold_fraction`。

重复记忆查询正常复用缓存结果，不因重复报错，但仍消耗有限的查询次数。仓库不包含旧模型后端、失效的原生 worker 入口和未实现的 WebArena 空壳；应用自行提供后端和 worker 命令。
