# 轻量来源检查

[English](provenance.md) | [简体中文](provenance.zh-CN.md)

更新：2026-11-09。`Validator(store)` 检查来源可追溯性和训练数据忠实度，不认证来源是否在语义上支持摘要。不调用 LLM 裁判，不强制完整回放，不要求摘要照抄原文，也不要求动作立即加分。

## 引用怎样产生和流转

应用为经历保存唯一任务 ID 和从零开始的步骤编号。Writer 生成自由表述的记忆和明确的 `supports` 引用，只能引用当前任务。Consolidator 可查看选中记忆及可访问来源步骤，再声明新摘要的父记录与来源引用。这些是模型声明的引用，不是自动证明的支持关系。替换摘要只能引用其声明的贡献父记录所关联的任务，父记录必须属于输入区域。

引用的经历须仍可访问，任务 ID 匹配，步骤为范围内的整数；布尔值、负数和越界步骤均拒绝。所有声明引用均须合格。正文和适用条件非空即可，不要求逐字摘录。错误摘要也可能引用真实来源，结构检查不能识别这种语义错误。

## 来源覆盖数与选择

`source_coverage_count(memory)` 对仍可访问、结构合法的引用按任务 ID 去重计数。同一任务引用多步或产生多条记忆都不增加覆盖数；不计算检索次数、父记录条数或生成问答数量。它是来源覆盖的代理指标，不是独立的语义支持分数。用进选择与废退输出保留都按该数排序，并列按种子随机处理。

为兼容已有存储和配置，保留 `supports`、`min_support_tasks`（默认 2）、`selection_policy="support"` 字段名，含义统一为结构性来源覆盖。Python 调用改为 `Validator(store)`，删除旧的外部校验器参数和 `support_count` 方法，改用 `source_coverage_count`。

## 训练材料与边界

决策示范取引用步骤的原始观察和真实动作，解码器负责复制；自行提供不同观察或动作会被拒绝。来源动作须被接受或明确标记为可执行，但无需立即加分。检查材料是否忠实原记录、输入是否仍为同一步、记忆版本是否绑定正确、引用是否在许可范围内。这里要求原样的是决策示范，不是摘要文字。

规则问答的答案复制摘要或指定正文片段，来源引用须为记忆引用的非空子集，不增加覆盖数。混合监督仍要求恰好一条规则问答和至少一条合格决策示范。预算、学生读取屏蔽、发布检查和退出规则继续有效。

对巩固输出，解码时逐条跳过格式错误的样本，记录其位置和原因；运行系统逐条检查、去除完全相同的样本，再按输出顺序保留，整次提案合计不超过 `max_examples_per_job`。启用审计回调时记录无效、重复和超额数量。正文引用重复时只计一次，同一决策引用重复也不使样本失效。混合监督要求一条去重后的规则问答和至少一条决策。缺少必要类型时，合格摘要及剩余材料仍保留在外部库，但不能参加混合训练；不增加自动补材料或重试队列。摘要本身的引用不合法，仍拒绝整组替换；正文和序列化数据预算继续有效。

学生屏蔽作用于外部记忆检索：排除目标版本、父记录、同源项和已识别的相同正文。决策历史由原步骤重新构造，不携带过去的检索消息；原生观察和动作即使与被排除记忆有文字重合，也照实保留。问答题目与答案文字重合时记录 `qa_text_overlap` 审计提示，不直接拒绝，例如短答案 `open` 也会出现在 `reopen` 内。生成提示仍要求避免照抄答案；明显自带答案等质量问题需抽查。准入不保证排除答案泄露，不认证语义正确，也不证明内化成功。

删除强制的 `observed_transition` 格式及原生回放模块。标准任务评分仍可使用官方评估器，与记忆准入分开。保存生成摘要与引用供质量抽查，在独立任务上衡量效果；准入本身不证明摘要真实或可泛化。
