# 架构概况

[English](architecture.md) | [简体中文](architecture.zh-CN.md)

前台在固定的模型与记忆版本上执行任务；后台负责写入、整理和学习。后续发布新版本时，已经开始的任务继续使用自己的视图。

```mermaid
flowchart LR
  T[任务与观察] --> R[有界检索]
  R --> A[策略与环境交互]
  A --> W[有来源的经验写入]
  W --> B[外部记忆库]
  B --> C[区域巩固]
  C --> B
  C --> S[选择合格记忆]
  S --> L[使用者提供的学习器]
  L --> P[准备并发布版本]
  P --> B
```

## 两条维护路径

常规批次默认每完成四个来源任务触发一次。Consolidator 读取有限区域及仍可用的来源，产出替换集合。先完成来源校验与原子替换，再考虑学习。每批最多选择一条有至少引用两个不同来源任务的合格记忆。默认混合监督包括规则问答与真实来源决策；学习器必须遵守指定材料、屏蔽规则和训练预算。

候选模型准备成功后，系统在同一事务中更新发布指针并退出所选记忆版本。学习失败会保留已提交的外部巩固结果。退出不以掌握测试为条件。

巩固输出的训练材料逐条解码和检查，坏样本不连带清空好样本；合格样本按输出顺序保留，合计不超过原有数量上限。缺少必要材料类型的摘要保留在外部库，不进入混合训练。不增加额外重试或补材料队列。

按较慢的固定轮次单独处理冷记忆，不依赖库占用率。对至少一个批次未访问的条目，按冷度从高到低依次选入 `region_token_cap`（默认 4096）的输入预算；装不下的跳过，继续检查后续条目，不再按条数比例截断。巩固结果按来源覆盖数排序，在 `min(floor(实际输入 token 数 / 2), output_token_cap)` 内保留完整条目。半预算根据实际选中的区域计算，不按输入配置上限计算。这类事件不训练；没有可用替换结果时保留原区域。

## 证据与权限

任务策略读取检索结果，不直接写库。Writer 读取一次公开经历；Consolidator 读取指定区域和可访问来源；内置轻量检查器核对来源，不认证摘要的语义正确性。摘要允许自由表述，语义质量通过后续评价检查。隐藏答案和评估元数据不属于公开经历。

训练时从外部记忆检索中排除目标、父记录、同源项和已识别的相同正文。历史由原始观察／动作步骤重新构造，不重放过去的检索消息；原生观察或动作与记忆文字重合，不会因此被拒绝。这限制的是外部记忆通道，不能保证输入中没有任何答案线索。只读评估不刷新记忆热度，也不恢复待处理学习作业。审计日志供分析，不作为可检索经验库。

每次训练都通过同一学习器接口传入 `histories` 和 `memory_context`。没有上下文时传空数据，不切换到会漏传历史的简化调用。

## 预算与恢复

`Config`、`Store`、`Runtime` 对活跃记忆、保留来源、队列、检索、监督材料和版本状态设置上限。SQLite 事务保护替换和发布；恢复记录保存待写经历、任务流位置与有界完成窗口。有限队列和任务期限支持到达负载计账。

使用者仍需在实际部署中约束总内存、显存、存储，并保证后端可取消。已有到达调度不是固定总时长评估器；全程截止、父链结算、检查点分支和科学评估需另行集成。不承诺无限去重或真实外部动作恰好执行一次。

继续阅读[组件约定](components.zh-CN.md)和[开发说明](development.zh-CN.md)。

旧参数 `cold_fraction` 已删除，已有配置须移除该字段。选区现在直接由输入 token 上限约束。

## 维护周期

`Config.batch_size` 控制用进周期，默认每 4 个已计账来源任务终局检查一次。`Config.capacity_interval_batches` 为大于 1 的整数，开发默认 4；废退每 `batch_size * capacity_interval_batches` 个终局执行一次，默认 16。成功、失败和拒绝都按现有完成计数推进，只读探测不计入。废退使用同一 Consolidator，不内化。同轮到期先用进、再废退。

每次废退最多处理 `max_capacity_regions` 个冷区域，默认 2；占用率低也会执行。空区域或失败消耗本轮尝试，下一周期再处理。后台繁忙时合并错过的周期，不积累无界补跑；持久化尝试标记避免重启后重复领取，崩溃中断的已领取尝试不保证重做。硬容量上限仍会拒绝超限写入，不额外触发整理。旧参数 `capacity_trigger_ratio`、`capacity_target_ratio` 删除，旧配置需改用 `capacity_interval_batches`。以上数值是开发起点，正式实验前校准并冻结。
