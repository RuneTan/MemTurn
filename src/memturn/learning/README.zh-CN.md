# 训练

[English](README.md) | [简体中文](README.zh-CN.md)

`base.py` 定义候选训练、推理准备和旧版本退出接口；`tiny_lora.py` 用冻结基座的小型动作分类器验证 CPU 梯度。

`huggingface.py` 在通过校验的输入/目标上进行可选的语言模型 SFT。它与推理共享提示和动作格式，屏蔽提示部分的损失，拒绝不稳定或超长样本，继续更新固定秩适配器，并在每次任务中新建优化器。仅 LoRA 参数允许训练。

公开来源轨迹和允许读取的外部记忆，均在执行屏蔽规则后提供；不需要教师模型。训练文件记录校验和与指标，本地发布与 vLLM 发布相互独立。

真实模型检查与远程兼容性状态见 [验证记录](../../../docs/validation.zh-CN.md)。

当前配置将全部选中样本打乱后完整遍历一遍（`epochs: 1`），梯度累积为一，每条样本
更新一次参数；不固定为两次更新，也不自动增大累积。token 和时限仍然有效；未完成
遍历时不发布、不退出记忆。显式提供 `steps` 的历史配置仍使用旧调度，以便复核。
训练记录包括
实际使用的来源步骤、输入步骤和哈希。当前路径保留原始状态与动作，不继承历史
检索内容；不再默认做初始状态投射。优化成功不等于模型已掌握经验。

`materials.py` 绑定样本与记忆版本／正文，区分文本问答和动作 JSON，并构造对应的静态训练输入。默认 `mixed` 要求两类样本，32 条预算包含问答。`tiny_lora.py` 只接受显式动作分类模式。见[当前协议](../../../docs/implementation_2026-10-24.zh-CN.md)。
