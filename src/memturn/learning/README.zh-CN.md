# 训练

[English](README.md) | [简体中文](README.zh-CN.md)

`base.py` 定义候选训练、推理准备和旧版本退出接口；`tiny_lora.py` 用冻结基座的小型动作分类器验证 CPU 梯度。

`huggingface.py` 在通过校验的输入/目标上进行可选的语言模型 SFT。它与推理共享提示和动作格式，屏蔽提示部分的损失，拒绝不稳定或超长样本，继续更新固定秩适配器，并在每次任务中新建优化器。仅 LoRA 参数允许训练。

公开来源轨迹和允许读取的外部记忆，均在执行屏蔽规则后提供；不需要教师模型。训练文件记录校验和与指标，本地发布与 vLLM 发布相互独立。

真实模型检查与远程兼容性状态见 [验证记录](../../../docs/validation.md)。

打乱后的训练计划先覆盖全部选中样本，再允许重复；必要时增大梯度累积，以保持配置的
优化步数。token 和时限仍然有效；样本未覆盖完整时不发布、不退出记忆。训练记录包括
实际使用的来源步骤、输入步骤和哈希。合成环境支持重放校验的初始状态输入；其他环境
需要自己的校验器。优化成功不等于模型已掌握经验。
