# Core package

[English](README.md) | [简体中文](README.zh-CN.md)

`contracts.py` defines tasks, episodes, memories, and model artifacts. `config.py` manages settings, and `tokens.py` provides token-counting interfaces.

| Directory | Contents |
| --- | --- |
| [memory](memory/README.md) | Memory storage, retrieval, source checks, and selection |
| [models](models/README.md) | Task policies, Writer, and Consolidator |
| [learning](learning/README.md) | Training material, learner interface, and model archives |
| [runtime](runtime/README.md) | Foreground tasks, background maintenance, and publication |
| [tasks](tasks/README.md) | Task environments and process integration |

See [Components and interfaces](../../docs/components.md) for how these parts connect.
