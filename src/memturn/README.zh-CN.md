# 核心包

[English](README.md) | [简体中文](README.zh-CN.md)

`contracts.py` 定义任务、经历、记忆和模型产物等数据类型；`config.py` 管理参数，`tokens.py` 提供 token 计数接口。

| 目录 | 主要内容 |
| --- | --- |
| [memory](memory/README.zh-CN.md) | 记忆存储、检索、来源检查和选择 |
| [models](models/README.zh-CN.md) | 任务策略、Writer 和 Consolidator |
| [learning](learning/README.zh-CN.md) | 训练材料、学习器接口和模型归档 |
| [runtime](runtime/README.zh-CN.md) | 前台任务、后台维护和版本发布 |
| [tasks](tasks/README.zh-CN.md) | 任务环境与进程接入 |

组件怎样连接，见[组件与接口](../../docs/components.zh-CN.md)。
