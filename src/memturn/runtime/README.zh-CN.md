# 运行调度

[English](README.md) | [简体中文](README.zh-CN.md)

`Runtime.run_task` 固定模型版本和有限记忆视图，执行初始检索与有限次按需检索，并记录任务结果。一个有队列上限的后台处理单元负责写入、巩固和可选训练。

检索调用和返回进入独立的策略历史。检索错误返回给策略，不再伪装成环境命令；环境
证据步骤的编号不变。无记忆评估同时关闭初始检索与额外检索。

先提交外部记忆替换，再通过独立发布事务更新模型指针并仅移除选中记忆的对应版本。训练失败保留外部记忆；容量任务不训练。

前台访问统计与后台维护使用不同的短锁；冷记忆提交拒绝已发生访问变化的快照。重启时重新排队尚未完成的 Writer 来源并取消未提交的模型任务；Writer 写入与阶段标记同时提交。

命令行检查在任务间等待后台。调度并发测试与真实服务延迟测试不同，本地 GPU 后端会将生成调用串行执行。

轨迹单独保存初始／追加检索中实际曝光的记忆；经验组件看不到原生任务私人清单或条件标签。静态训练使用原生环境历史和重新检索的允许记忆，不继承旧检索正文与查询。
