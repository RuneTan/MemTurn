# 记忆

[English](README.md) | [简体中文](README.zh-CN.md)

`store.py` 在 SQLite 中保存活跃记忆、来源、有限的任务/结果记录和模型指针。任务持有不可变快照，调用模型时不占用数据库事务。

`validation.py` 将来源与训练目标交给独立环境校验器检查。支持数按有效的不同任务 ID 计算，并检查声明的贡献父项。`policies.py` 至多选择一条合格记忆，并将完整容量巩固结果装入实际输入 token 数一半的预算。

`retrieval.py` 是可替换的词法检索器；`consolidation.py` 是确定性的开发组件，与模型生成的经验组件分离。

正文、来源/样本、元数据、快照和数据库页分别限额；这不等于限制整个进程内存或远程缓存。审计文件不作为可检索记忆。
