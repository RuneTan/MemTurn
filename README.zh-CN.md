# MemTurn

[English](README.md) | [简体中文](README.zh-CN.md)

**让 Agent 在有限的存储和计算预算下，持续整理和学习任务经验。**

Agent 连续执行任务时，会积累越来越多的经历。哪些值得继续保存，哪些值得花计算去学习，又该怎样给新经验腾出空间？MemTurn 围绕这个问题，把外部记忆的整理和模型的持续更新接在一起。

系统用两种节奏管理经验：

- **用进：整理近期用到的经验，选一条来学。** 将新记录和近期检索过的记忆交给 Consolidator（经验整理器），生成摘要、规则问答和决策示范。随后从库中选出来源覆盖较广、训练材料齐备的一条摘要，用它微调任务模型；新版本发布后，移除对应的外部记忆。
- **废退：隔更长时间，压缩较少使用的经验。** 按冷度选取一批记忆，交给同一个 Consolidator 整理，在原输入一半的篇幅内保留摘要，为后续经验腾出空间。

两条路径都按固定轮次运行。任务模型采用冻结基座与固定秩 LoRA，Writer（经验记录器）和 Consolidator 在任务流中保持固定。研究关注的是：这样分配记忆和学习预算，能否提高后续任务的累计收益，并让早期经验持续发挥作用？

## 一条经验怎样流转

**执行任务并检索记忆 → 记录经历 → 整理为摘要与训练材料 → 选择摘要微调 → 发布模型并移除对应记忆。**

选择摘要时，默认优先考虑它引用了多少个不同任务。比如，两条都满足训练条件的摘要分别来自三个和两个任务，就优先考虑前者。每轮用进最多学习一条；其余摘要继续留在记忆库中供检索或后续学习。

## 从哪里开始

仓库提供任务调度、记忆管理、经验整理、训练接口和模型版本管理。接入任务环境与模型后，可用它搭建持续学习实验。
